## 🔬 Featured Projects

**🤖 [Vision-Guided Pick-and-Place](https://github.com/mariemkbaier/cv-robotics-pipeline)**
Camera-to-grasp pipeline with no privileged information in the loop: hand-eye calibration (AX = XB), 6D pose from PnP with ambiguity handling, IK via damped least squares. The eval harness exists because an error in any one stage is indistinguishable from the others at the gripper — so it attributes error to the right stage.
`Python` `OpenCV` `kinematics` `calibration`

**🏢 [Test-Time Adaptation for Smart Buildings](https://github.com/mariemkbaier/TTA-Test-Time-Adaptation)**
Cross-building activity recognition and occupancy estimation on WSU sensor data under a deployable online protocol — both transfer directions, chance baselines, paired bootstrap intervals. Found that stride-1 windowing under a random split inflates source macro-F1 to 0.998, and that two of three published methods do not adapt at all here.
`PyTorch` `domain adaptation` `evaluation protocols`

**🎙️ [Local-First Meeting Assistant](https://github.com/mariemkbaier/meeting-assistant)**
Fully on-device meeting assistant: streaming ASR over WebSockets, retrieval across documents and past transcripts, grounded spoken Q&A via a local LLM. No external API calls, no per-token cost, no audio leaving the machine.
`faster-whisper` `FAISS` `Ollama` `FastAPI`

**🏷️ [Automated Annotation Pipeline](https://github.com/mariemkbaier/auto_labelling_tool)**
Automatic image labeling for detection datasets, with pseudo-label quality and annotation-noise analysis feeding back into the training loop.
`SAM2` `Grounding DINO` `SAHI`
